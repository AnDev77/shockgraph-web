# 연구 결과와 화면 표시의 경계

2026-10-28 기준. 이 문서는 연구 파이프라인을 프론트엔드에 연결할 때 필요한 인수 조건이다. 비공개 가격·오차·신뢰구간 수치를 포함하지 않는다.

| 화면에 필요한 자료 | 현재 화면 | 연결 전 필요한 검증 |
|---|---|---|
| FOMC·CPI·PCE 일정 | 기관 공식 페이지 링크만 제공 | 공식 원문 URL, 시간대, 최초 게시·수신 시각, 변경 또는 취소 처리 |
| QQQ·SPY 시장 차트 | TradingView 외부 위젯 | 실제 모바일 브라우저 로드·차단 시 대체 링크, 표시 권리와 개인정보 고지 |
| 발표 전후 종목 반응 | 수치 비노출 | 두 종목 공통 거래일, 동일 사건 창, 당시 이용 가능한 가격본, 공개 재배포 권리 |
| 미래 위험 예측 | `HOLD` 표시 | 사전 기록, 성숙한 5·20거래일 정답, 같은 기간 기준선, 독립 시험, 불확실성 |
| 종목별 대화 | 연결 전 빈 화면 | Java 로그인·서버 주체 확인, 읽기/쓰기 권한, 저장·재접속·신고/차단 정책 |

연준 연구의 고빈도 실현 변동성과 현재 일봉 기반 5·20일 위험은 목표와 자료 빈도가 다르다. 따라서 논문에서 특정 방법이 유리했다는 결과를 QQQ·SPY의 자체 성능으로 옮겨 적지 않는다. 사건의 발표 전후 가격 차이는 관측 비교이며 사건의 인과효과나 종목의 미래 방향 예측이 아니다. 같은 거래일·같은 시작일의 여러 종목이나 겹친 미래 기간을 독립 표본으로 세지 않는다.

연구 트랙은 데이터 이용 시각·원본 무결성·공통 날짜 범위를 먼저 확인하고, 모델 후보는 동일한 시간순 시험에서 단순 기준선과 비교한다. 웹 트랙은 이 판정 상태를 받은 그대로 표시한다. 실제 채점과 사용자 수요 확인이 끝나기 전에는 `HOLD`를 해제하지 않는다.

참고: [연준 FEDS 연구](https://www.federalreserve.gov/econres/feds/linear-and-nonlinear-econometric-models-against-machine-learning-models.htm), [기존 연구 검증표](https://github.com/AnDev77/ShockGarph_AI/blob/main/docs/autonomous-development-scorecard.md). 연구 결과의 최신 운영 상태는 AI 저장소와 비공개 감사 기록에서 별도로 확인해야 한다.
