# React·TypeScript 화면 전환 리뷰

## 시작과 범위

기존 웹은 문자열 HTML과 쿼리 매개변수 기반 단일 스크립트였다. Figma의 홈·종목 상세·토론방 진입 화면과 공식 출처·연구 보류 표시를 유지하면서 React 학습 표본이 될 구조로 옮겼다. 회원·채팅 서버 및 공식 발표 자동 API는 아직 없다.

## 구현

Vite·React·TypeScript의 엄격 검사, React Router의 화면 주소, 기능별 컴포넌트, 공통 레이아웃과 TanStack Query Provider를 도입했다. 종목 허용 목록은 QQQ/SPY이며 그 외 상세·토론 주소는 홈으로 이동한다. TradingView 외부 스크립트는 종목 상세에서 최초 한 번만 추가하고 컴포넌트 이동 시 차트 요소를 정리한다. 공식 원문 링크, 연구 `HOLD`, 비활성 채팅 입력을 유지했다. 과거 문자열 렌더러와 시험은 삭제했다.

## 중간 오류와 조치

처음 lint는 삭제되지 않은 옛 스크립트의 브라우저 전역에서 실패했고, 처음 Vitest는 옛 Node 내장 시험 파일을 중복 수집했다. 옛 파일을 제거하고 React Testing Library 시험으로 바꿨다. 종목 카드의 접근 가능한 링크 이름이 예상 공백과 달라 시험이 실패했으므로 사용자에게 보이는 종목 이름으로 조회하도록 수정했다. 발표 앵커가 홈 링크와 함께 선택된 것으로 표시되는 문제도 일반 링크로 분리했다.

## 검증과 한계

로컬 `npm run check`의 TypeScript·ESLint 오류 0건, React Testing Library의 화면 시험 4개 통과, `npm run build`의 HTML·CSS·JS 산출을 확인했다. 시험은 홈의 공식 출처와 연구 보류, SPY 라우트·차트 출처, 비활성 채팅, 미지원 종목의 홈 이동을 다룬다. 위젯 스크립트는 상세 화면에서 1개만 추가되는지 검사한다. 실제 브라우저의 외부 위젯 로드, 배포 호스트의 SPA rewrite, 회원·채팅, 공식 일정 자동 수집, 원격 CI는 검증 전이다. 패키지 설치·정적 빌드 통과는 독립 미래 예측 성능이나 사용자 수요의 근거가 아니다. 공개 가격·비공개 성능 수치를 추가하지 않았다.
