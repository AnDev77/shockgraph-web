# QQQ·SPY 발표 근거 화면 리뷰

기준일: 2026-11-09. 웹 `main` `f64feb8972606275061c613a78f1af361ba20aeb`에서 시작했다. 기존 상세와 종목방은 공식 기관 링크를 일부 보여 주지만, 종목별로 발표 근거를 읽는 전용 화면과 이동 경로는 없었다. 원격 최신 커밋을 확인하고 별도 작업 트리에서 구현해 이전 기능 브랜치의 변경을 건드리지 않았다.

## 구현과 범위

- `/assets/QQQ/evidence`, `/assets/SPY/evidence`: FOMC·CPI·PCE 탭에서 기관, 먼저 확인할 항목, 공식 발표 일정/자료 링크를 보여 준다. 지원하지 않는 종목은 홈으로 보낸다.
- 상세·종목방에서 해당 종목의 근거 화면으로 이동한다. 원문 목록은 기존 `src/features/events/sources.ts`를 재사용한다.
- 과거 사건 반응, 예측 위험, AI 해설은 데이터·연구 API가 연결되지 않아 `검증 대기`/`연결 전`이라고 표시한다. 일정 링크를 특정 발표 결과나 AI 답변으로 오인하게 만드는 숫자와 문구는 넣지 않았다.
- 변경량은 화면/이벤트 메타데이터, 라우팅·진입 링크, 스타일, 단위·직접 URL·브라우저 시험, 이 리뷰다. 회원·채팅 저장, 가격 수집, 모델 코드는 바꾸지 않았다.

## 시험과 오류

중간 시험에서 문장 일부를 정확 일치로 찾던 단위 시험 1건이 실패했다. 실제 문단의 일부임을 확인하고 부분 일치 검사로 고친 후 `npm run check`와 `npm test`의 19개 시험이 통과했다. `npm run build`, `npm run verify:dist`, `npm run smoke:routes`는 빌드 HTML·자산 2개와 직접 URL 9개를 확인했다.

`npm run test:browser`는 로컬 Playwright 전용 Chromium 실행 파일이 없어 6건 모두 시작하지 못했다. 설치된 `/usr/bin/chromium`으로 재시도했으나 이 환경이 Chromium의 소켓 생성을 `Operation not permitted`로 막아 역시 시험 본문에 진입하지 못했다. 이 실패는 로컬 화면 검증 성공으로 세지 않고 원격 PR의 데스크톱·모바일 브라우저 게이트를 별도 확인했다.

[초안 PR #3의 Web quality 실행](https://github.com/AnDev77/shockgraph-web/actions/runs/42572243442)에서 `npm ci`, 타입·린트, 단위 시험, 빌드, 자산 검사, 직접 URL 검사, Playwright 설치와 데스크톱·모바일 브라우저 시험 단계가 모두 성공했다. 이 게이트는 합성 환경의 화면 동작을 확인하며 실제 배포 도메인과 외부 기관 연결을 확인한 것은 아니다.

## 객관적 판정과 다음 조건

이 변경은 공식 기관 원문으로 가는 종목별 화면과 상태 구분이라는 사용자 흐름 한 건을 완성한다. 연구 모델의 예측력, 발표별 가격 반응, API 운영 연결, 실제 사용자 수요는 검증하지 않았다. AI 해설을 열려면 원문 버전·발표 시각·검색 근거와 검증된 분석 API를 연결하고, 근거가 없거나 발표 전인 경우 답변을 보류하는 계약이 필요하다. 배포 전에 실제 모바일·데스크톱 화면과 링크, 외부 자료 접근을 확인한다.
