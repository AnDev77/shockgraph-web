# 직접 경로·발표 이동 검증

2026-10-29, 초안 PR #1의 첫 화면 배포 준비 작업.

## 시작 근거

- 공개 `main`의 홈은 열렸지만 `/assets/QQQ` 직접 접근은 404였다. 초안 PR의 Vercel rewrite는 아직 공개 주소에 반영되지 않았다.
- 공개 SPY 상세에서 하단 `발표`를 눌렀을 때 `/#sources`로 주소가 바뀌어도 공식 자료 영역이 보이지 않았다. 브라우저에서 스크롤 위치가 유지되는 것을 재현했다.
- 초안 PR의 이전 원격 품질 게이트는 성공했지만, 직접 URL과 빌드 자산을 HTTP로 요청하는 검사는 없었다.

## 구현과 중간 검증

1. Router의 해시가 `#sources`가 되면 공식 자료 영역으로 스크롤한다. SPY 상세에서 하단 토론 메뉴가 같은 종목방으로 이어지는지 시험도 보강했다.
2. Vite 빌드 미리보기 서버를 열고 `/`, `/assets/QQQ`, `/assets/SPY`, `/rooms/QQQ`, `/rooms/SPY`의 HTML 상태와 React 시작점을 요청으로 검사한다. 홈 HTML에서 참조하는 JS·CSS 두 자산은 HTML 대신 실제 자산 응답을 받아야 한다.
3. CI 빌드 이후 이 검사를 실행한다. 첫 로컬 시도에서는 새 스크립트의 `fetch`와 `URL` 전역 이름에 린트 오류가 났다. `URL`을 Node 모듈에서 가져오고 `globalThis.fetch`를 사용한 뒤 전 단계를 다시 실행했다.

## 완료 근거와 해석

- `npm run check`: TypeScript와 ESLint 통과.
- `npm test`: 화면 시험 5개 통과. 신규 시험은 SPY 상세에서 `발표`를 눌러 공식 발표 영역 이동 호출을 검증한다.
- `npm run build`: Vite 프로덕션 빌드 성공. `npm run verify:dist`: 빌드 HTML과 참조 자산 2개를 확인했다.
- `npm run smoke:routes`: 빌드 미리보기의 직접 URL 5개와 JS·CSS 2개 응답 통과. `git diff --check` 통과.

코드 및 문서 작업은 스크립트 1개 추가, 기존 파일 6개 수정, 화면 시험 1개 추가다. 로컬 미리보기는 Vite가 제공하는 SPA 경로 처리를 확인한 것으로, Vercel의 rewrite 배포 성공 증거는 아니다. 초안 PR의 원격 CI와 공개 주소의 직접 URL·새로고침, 모바일·데스크톱 브라우저, 외부 위젯 동작은 별도 확인이 필요하다. 연구 성능과 사용자 수요를 이 화면·경로 검사로 판단할 수 없으며 예측 성능은 `HOLD`다.
