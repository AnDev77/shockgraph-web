# 공개 홈 점검과 UI 문구 개선

## 시작 근거

2026-10-29 공개 주소 `https://shockgraph-web.vercel.app/`를 브라우저에서 확인했다. 홈은 열리고 내부 링크로 QQQ 상세와 토론방 준비 화면까지 이동했다. QQQ의 외부 차트도 화면에서 표시됐다. 그러나 `/assets/QQQ`를 주소창에서 직접 열면 Vercel 404가 발생했다. `main`에는 아직 초안 PR의 SPA rewrite가 없다.

## 변경과 이유

- 홈의 추상적인 제목과 영어 소제목을 실제 제공하는 내용인 미국 경제 발표 자료와 QQQ·SPY 차트에 맞췄다.
- 공식 일정이 자동 갱신되는 것처럼 보이지 않도록 기관 사이트에서 확인한다는 안내를 유지하면서 문장을 짧게 했다.
- 사용자가 해석하기 어려운 화면의 `HOLD` 표기를 `공개 전`으로 바꿨다. 실제 결과로 정확도를 확인하기 전까지 예측값을 보여주지 않는다는 의미이며 연구 판정을 승인으로 바꾸지 않았다.
- 로그인과 채팅이 작동하는 것처럼 읽히는 버튼과 토론방 진입 문구를 `미리보기`·`채팅 준비 중`으로 수정했다. 중복된 본문 건너뛰기 링크 하나를 제거했다.

## 검증과 한계

로컬 TypeScript·ESLint 검사 오류 0건, 사용자 화면 시험 4개 통과, Vite 빌드와 빌드 HTML의 JS·CSS 파일 검사 통과, `git diff --check` 통과를 확인했다. 시험은 종목 링크와 공식 원문, 예측 정보 공개 전 표시, 상세 차트 출처, 비활성 채팅, 미지원 종목 이동을 검사한다. 변경된 문구가 Vercel의 공개 화면에 반영됐는지는 아직 확인하지 못했다. 실제 URL 새로고침 404는 PR 수정이 배포된 뒤 다시 시험해야 한다. 모바일 화면, 외부 차트의 다른 브라우저 동작, 회원·채팅 서버, 실전 예측 성능과 사용자 수요도 이 작업에서 확인하지 않았다.

초안 PR #1의 변경 커밋 `49e68f7`에 대해 GitHub Actions `Web quality`의 설치·타입/린트·시험·빌드·산출물 검사가 모두 성공했다. Vercel PR 미리보기 배포는 Ready로 표시됐지만 로그인 보호 화면으로 이동해 변경된 UI와 직접 URL 접근을 브라우저에서 검증하지 못했다. 이 두 상태를 공개 `main` 화면의 성공으로 합산하지 않는다.
