# 독립 웹 화면과 연구 표시 경계 리뷰

## 시작

AI 저장소의 초안 PR #13에는 QQQ·SPY 전환형 정적 차트 화면이 있으나, 프론트엔드는 별도 레포지토리로 분리하기로 했다. 새 Figma 초안에는 홈·종목 상세·종목방 세 화면이 있다. 실제 채팅·관심 목록 저장·공식 일정 자동 목록은 아직 없다.

## 구현

별도 `shockgraph-web` 프로젝트에서 세 화면을 쿼리 라우트로 구성했다. QQQ·SPY 허용 목록, 공식 기관 원문 링크, TradingView 제공 차트, 연구 `HOLD`와 채팅 연결 전 상태를 명시한다. 패키지 의존성 없는 정적 빌드와 Node 내장 시험·CI를 추가했다. PR #13의 차트 속성과 공식 원문 링크를 참고했으며 AI 저장소의 wheel이나 비공개 원본은 옮기지 않았다.

## 검증과 한계

로컬 `npm run check`에서 JavaScript 세 파일 구문이 통과했고, Node 내장 시험 5개가 모두 성공했으며, `npm run build`가 정적 산출물 네 파일을 만들었다. 시험은 임의 종목 입력 제한, QQQ·SPY 라우트, 기관 링크와 비공개 수치 비노출, 키보드 이동, 외부 위젯의 상세 화면 전용 로드를 다룬다. 생성한 `dist/`를 로컬 HTTP 서버로 열어 HTML·CSS·모듈 두 개의 200 응답과 비어 있지 않은 본문도 확인했다. 실제 위젯 로드, 모바일 렌더링, Java 로그인·채팅, FastAPI 사건 응답, 새 원격 CI와 공개 배포는 아직 검증하지 않았다. 공개 데이터 사용권·독립 미래 모델 성능·사용자 수요는 `HOLD`다. 새 레포지토리 원격 생성 도구가 없어 현재 로컬 프로젝트만 준비했다.

## 다음 인수 조건

원격 레포지토리를 만들고 CI를 확인한 후 호스팅과 실제 브라우저 점검을 진행한다. 종목방은 서버 인증·저장·재접속·권한 시험을 통과하기 전까지 비활성이다. 연구 수치는 별도 연구 판정을 통과한 자료만 게시한다.
