# 열린 프론트 PR 통합 리뷰

기준: 2026-11-16. 사용자가 열린 프론트 작업의 병합을 승인했다.

## 시작과 선택

- `main`의 #7·#8과 새 #11을 확인했다. #11의 원격 Web quality와 Vercel 미리보기가 성공했고, #11을 먼저 병합했다.
- #3·#4는 이전 `main` 기준이라 충돌했고, #5·#6은 #4를 기준으로 쌓여 있었다. 이전 브랜치를 그대로 병합하면 새 홈·브리핑·대표 종목 화면과 최신 계획을 되돌릴 수 있어 현재 `main`에서 별도 통합 브랜치를 만들었다.
- #5의 QQQ·SPY 관심 목록 기능은 #11의 회원별 관심 목록에 포함되어 있다. 오래된 두 번째 구현과 그 구현 전용 시험은 중복 적용하지 않았다. #3의 발표 근거 화면, #4의 읽음 커서 수정, #6의 가입 후 종목방 복귀·재시도는 현재 구조에 맞게 통합했다.

## 중간 오류와 수정

- 이전 화면과 새 상세 화면이 충돌해 QQQ·SPY에만 근거 링크를 넣고, CAMT·SPCX·AVGO의 미지원 기능을 켜지 않았다. 최신 제품 방향·일일 계획·AGENTS 파일을 유지했다.
- 첫 단위 시험에서 이전 홈 제목을 기대하던 근거 화면의 잘못된 경로 시험 1건이 실패했다. 최신 홈 제목으로 고쳤다. Playwright 로컬 실행은 Chromium 전용 실행 파일이 없어 시험 본문 전에 중단됐다.
- Playwright 설정에는 기존 대표 종목·브리핑·관심 목록 플래그와 신규 채팅 플래그를 함께 적용했다. 채팅 POST의 `RoomSymbol` 제한과 응답 유효성 검사를 유지했다.

## 로컬 결과와 남은 확인

- `npm run check`, 단위 시험 28건, `npm run build`, `npm run verify:dist`, `npm run smoke:routes`의 직접 URL 12개와 자산 2개가 통과했다.
- 원격 PR의 새 커밋에서 모바일·데스크톱 Playwright 및 Vercel 상태를 확인한 다음에만 통합 병합을 판단한다.
- 실제 EC2·SMTP·Java 채팅·회원별 저장·외부 차트·브리핑은 이 합성 시험으로 입증되지 않는다. 금융 예측 성능과 제품 수요도 HOLD다.
