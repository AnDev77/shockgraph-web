## 기존 초안 통합 의존성

2026-11-15 조회에서 웹 #4(채팅 조회 수정), #5(회원별 관심 목록), #6(가입 후 토론방 복귀), #7(SPCX/CAMT 상세)가 열려 있다. Java #16(관심 목록), #17(IP TLS 갱신), #20(배포 진단), #21(EC2 후보 기동), #22(채팅 제한) 등도 열려 있다. 이 기능들은 main에 이미 포함됐다고 가정하지 않는다. 월요일에 각 PR의 실제 기반·중복 변경·필수 선행 PR을 확인하고 필요한 변경을 통합 브랜치에서 시험한 뒤 승인 대상으로 제시한다. #21만 병합하면 공개 운영 배포가 끝나는 것이 아니다. 기존 스키마·Nginx·인증 설정과 공개 전환 경로까지 확인한다. 최신 계획은 이 문서를 유지하고 과거 PR의 일일 계획으로 덮어쓰지 않는다.

## 월요일 해결해야 할 외부 분기

1. Java #21은 마지막 확인에서 초안이며 병합 승인이 아직 없다. 사용자의 자동 병합 금지는 유지한다. 역할/배포 권한·환경 변수 존재를 확인하고 실제로 필요한 승인만 요청한다. 기존 읽기 전용 SSM 성공은 앱 기동 권한 확인이 아니다.
2. LLM·임베딩 제공자의 운영 키와 월 지출 상한. 계정에 설정돼 있는지 우선 확인하고 없을 때만 사용자에게 비밀 저장소 등록을 요청한다. 키는 채팅으로 받지 않는다. 화요일까지 호출 불가면 수요일 실제 AI 요약 목표가 막힌다고 즉시 알린다.
3. 수집 원문의 허용 범위·정상 응답. 뉴스 공급원 미확보 시 공식 공시·IR 소식으로 범위를 명시한다. 독립 출처 부족이면 판단을 보류하며 가짜 근거를 추가하지 않는다.

## 시험과 완료 조건

- 소프트웨어: 웹 check/test/build/dist/routes + 모바일/데스크톱. Java 전체 시험·Redis·JAR. Python wheel·포함 파일·Ruff/Pyright·전체 시험. 마지막 커밋 CI와 실제 운영 인수를 각각 기록.
- 평가: 문서 20개 고정 세트에 종목·시각·핵심 사실·출처·보류 필요 여부를 사람이 지정한다. 출처 ID 유효성 100%, 표본 내 꾸며낸 핵심 사실/수치 0건, 기간/종목 혼입 0건을 출시 기준으로 제안한다. 실패한 범주는 공개 판단을 차단한다. 이는 달성 실적이나 미래 수익률 정확도가 아니다.
- UI: 360px~1440px 가로 넘침 없음, 출처 키보드 접근, 생성 도중 이탈/재접속 복구. 참고 문서를 복제한 모의 화면과 실서비스 인수를 구분한다.
- 운영 목표(실측 전): 캐시 응답 p95 1초 이내, 생성 완료 p95 30초 이내·60초 제한, 동시 생성 1건부터. 예상 사용자 10명 동시 조회로 API·큐·메모리·비용 측정 후 조정. 달성하지 못하면 실제 값을 기록.
- 장애: LLM 429/timeout, 수집 실패, 잘못된 JSON/인용, worker 종료, Redis 장애, DB 재접속, Nginx 전환 실패를 검증. MySQL 볼륨 삭제 금지, 추가 스키마만 먼저 적용, 이전 Java 이미지와 공존 확인.

## 범위 절감 순서

자유 질문, 자동 알림, 임의 종목 검색, 월가 목표가, 추가 토론방을 뒤로 미룬다. 핵심 '실자료 검색→요약→출처→근거 판단'을 가짜 응답으로 대체하지 않는다. 운영 경로가 막히면 필요한 외부 입력·정확한 실패 단계와 새 예상일을 보고한다. 기능을 줄여도 실제 AI 브리핑을 보지 못했다면 이번 목표 미달이다.

## 이번 계획 작업 기록

웹 main과 종목 확장 #7의 HomePage·AssetPage·router, 기존 계획과 중간 평가를 읽었다. 공식 토스 공개 페이지와 RAG/LangGraph/SEC 문서를 확인했다. 계획 3개와 AGENTS 우선순위를 수정했다. 실행 코드는 변경하지 않아 새 빌드·배포·성능 시험을 수행하지 않았다. 과거 비공개 진행/장애/검증표 전체는 업로드하지 않는다.
