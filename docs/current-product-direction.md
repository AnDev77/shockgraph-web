# 현재 제품 방향: 관심 종목 RAG 브리핑

제품 범위 기준일 2026-11-16 KST, 연동 상태 갱신 2026-11-20 KST. 이 문서와 [일일 계획](daily-work-plan.md)이 현재 기준이다. 과거 방향과 일정은 Git 이력에 남긴다. Java가 공시 RAG·검토·공개 브리핑을 소유하고 Python은 예측·가격 연구를 담당한다. [CAMT Java 연결 절차](camt-java-briefing-connection.md)의 자동 시험은 운영 성과가 아니다.

## 제품 약속과 첫 범위

관심 종목을 고르면 지원되는 차트와 최근 소식, 강세·약세 근거, 원문을 한 화면에서 확인한다. 홈 대표 종목과 관심 목록의 시작 제안은 **캠텍(CAMT) → 스페이스X(SPCX) → 브로드컴(AVGO)** 순서다. 신규 사용자는 제안 목록을 편집할 수 있고, 이미 저장한 목록(직접 비운 목록 포함)은 교체하거나 자동으로 채우지 않는다. 기존 QQQ·SPY는 시장 비교 차트와 종목방에 유지한다. ETF 브리핑은 공식 거시 자료와 ETF 발행사 자료로 별도 연결한다. 구성 기업 한 곳의 기사를 ETF 전체 호재로 자동 확장하지 않는다.

| 공개 범위 | 정책 |
|---|---|
| 홈 대표·기본 관심 종목 | CAMT·SPCX·AVGO. 상세·차트·공식 자료부터 확인하며 CAMT 수집 구현을 먼저 연결한다. |
| 검색·관심 저장 | 미국 주요 거래소의 활성 보통주·ETF부터 확대. 티커·영문명·제한된 한글 별칭을 검색하고 관심 등록 가능. |
| 차트 | 상세 진입 시 승인된 외부 위젯을 한 개만 로드. 종목별 제공 범위·지연 여부·실패 상태 표시. |
| AI 브리핑·예측·채팅 | 브리핑은 출처 검증을 마친 종목만 허용. 예측은 독립 검증 범위를 따로 표시. 채팅은 QQQ/SPY 유지. 검색되더라도 나머지 기능을 자동 개설하지 않는다. |

토스증권처럼 검색과 상세 탐색이 이어지는 경험을 목표로 한다. 국내·전 세계·OTC·파생상품을 한꺼번에 포함하거나 전 종목 실시간 시세·뉴스·AI를 제공하는 목표는 별도다. 종목 목록과 가격 표시 허용 범위는 공급원마다 별도로 확인한다. 거래 화면을 만들거나 사용자의 관심 종목을 매수 추천으로 표현하지 않는다.

- 화면 분류: 강세 우세 / 약세 우세 / 혼재 / 판단 보류. 최근 소식의 방향성 해석이며 미래 수익률 예측이나 매수·매도 명령으로 표현하지 않는다.
- 기본 근거 기간은 최근 7일. 새 소식이 없으면 그 사실을 표시하고 최근 30일 이내의 배경 자료는 날짜가 있는 별도 영역으로 분리한다. 과거 자료를 오늘의 새 소식으로 제시하지 않는다.
- 각 사실과 해석에 출처 ID·발표일 연결. 확인된 사실, 기업의 주장, AI 해석을 분리한다. 강세 주장에는 반대 근거와 미확인 조건도 검색한다.
- 단일 기업 IR만 있으면 그 자료 요약은 제공하되 독립 교차 확인 부족을 표시하고 종합 판단을 보류한다. 보도 재배포·같은 공시 재인용은 독립 출처로 세지 않는다.
- 실적·가이던스·수주·규제·자금조달·희석·운영 사건을 구분한다. 기사 수나 단순 긍정 표현 개수로 점수를 계산하지 않는다. 가격에 이미 반영됐는지 모르면 명시한다. 검증되지 않은 상승 확률·목표가·확신 백분율은 표시하지 않는다.
- 연구 모델, 리밸런싱, 자유형 장문 상담, 매매, 노트·결제·추가 종목방은 이번 주 범위에서 제외한다. 연구 코드와 비공개 데이터는 보존한다.

## 자료·모델의 외부 조건

첫 데이터 경로는 SEC 공시와 회사 공식 IR/보도자료다. SEC submissions API의 메타데이터만으로 뉴스 요약을 만들지 않고 연결된 실제 문서를 읽는다. CAMT의 6-K/20-F 등 발행인별 양식을 지원한다. 뉴스 제공자는 수집·저장·LLM 전송·요약 표시 조건을 확인한 공급원만 연결한다. 공식 웹페이지가 공개됐다는 이유만으로 무제한 저장·재배포를 허용한다고 가정하지 않는다. 허용 여부 불명확한 문서는 링크만 제공한다.

종목 식별은 [캠텍 공시](https://www.sec.gov/Archives/edgar/data/1109138/000117891326005000/zk2636329.htm), [스페이스X 상장 공지](https://www.nasdaqtrader.com/TraderNews.aspx?id=DTN2026-8)와 [SEC 10-Q](https://www.sec.gov/Archives/edgar/data/1181412/000162828026066880/spcx-20260930.htm), [브로드컴 EDGAR](https://www.sec.gov/edgar/browse/?CIK=1730168&owner=exclude)로 확인했다. 스페이스X 미국 첫 거래일은 2026-06-12이며 재사용된 `SPCX`의 상장 전 다른 증권 시세를 차트·연구 입력에 붙이지 않는다. CAMT는 Nasdaq과 TASE에 같은 티커로 상장되므로 미국 화면은 Nasdaq/USD로 명시한다.

LLM·임베딩 API 키와 사용 한도는 아직 이번 작업에서 확인하지 않았다. 공급자 어댑터를 분리하고 모델 버전을 고정한다. 승인된 공급자가 없으면 LLM 호출 대신 상태를 반환하며 가짜 요약을 공개하지 않는다. 운영 키는 브라우저·Git·PR로 전달하지 않는다. 요약 비용은 회원별이 아니라 종목·근거 묶음별 공유 캐시로 줄인다.
